6 个指标卡的精确算法

每个指标对应哪个表、哪个字段，避免看数时对不上
辅导次数
N 次
作业表总行数
= cache.hw.length
累计时长
N 分钟
作业表 时长(分钟) 求和
= Σ 时长(分钟)
错题总数
N 道
错题表总行数
= cache.wrong.length
待订正
N 道
错题表 已订正 ≠ true 的行数
= 总数 − 已订正数
需加强
N 次
作业表 掌握情况 = 需加强 的次数
注意：统计的是辅导记录，不是错题
订正率
N%
= round(已订正 ÷ 错题总数 × 100)
错题为 0 时显示 0%
最容易看错的一点：「需加强」数的是辅导记录里掌握情况填了"需加强"的条数，跟错题表完全无关；「待订正」只数错题表。两个数字对不上是正常的。

专属信息区 · 四块的取值与排序规则

同一批数据，四个视角；排序和条数都是固定的
块取哪些数据排序 / 条数 / 展示规则
最近辅导 作业表全部记录 按日期倒序取 前 6 条；每行左侧色条按掌握情况变色：掌握一般需加强；行内显示 科目 · 辅导内容 + 掌握情况标签 + N 分钟（有备注再拼「· 备注」）
科目分布 作业表，按 科目 分组 柱状图，按辅导次数计数；标题「科目分布（按辅导次数）」；科目取 语文/数学/英语/其他
错误类型分布 错题表，按 错误类型 分组 柱状图（红色系，与科目分布区分），标题「错误类型分布（主要失分原因）」；用来一眼看出主要失分原因
错题本 错题表全部记录 未订正优先（排在最前），同状态内按日期倒序；未订正行浅红底；已订正显示 已订正 · 重做结果（一次通过 / 再次出错 / 未重做）

常见操作

页面是只读视图，所有录入都去资料库的两张表
我要…怎么做
记一次辅导「作业辅导记录」表加一行：日期 / 科目 / 辅导内容 / 时长(分钟) / 掌握情况 → 刷新页面，指标卡和最近辅导自动更新
记一道错题「错题本」表加一行：日期 / 科目 / 错题摘要 / 错误类型（已订正先不勾）→ 错题本区块置顶出现

看哪科辅导最少信息区「科目分布」柱状图，最短的柱就是辅导最少的科目
看主要失分原因信息区「错误类型分布」，最高的柱就是主要失分类型（计算错误 / 审题不清 / 概念不清 / 粗心 / 不会做）
抓还没搞定的错题信息区「错题本」最上面几条（浅红底、标"待订正"）就是待清清单
看整体投入指标卡「辅导次数」+「累计时长」，两个一起看才知道单次平均 时长 ÷ 次数
