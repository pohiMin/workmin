旺旺膨化 · 三区块详解

纵向铺开（不堆叠）：信息录入 → 每日打卡 → 客户档案
区块能做什么操作路径 / 要点
信息录入 随手记：语音或文字一句，带标签 + 关联客户，写进「随手记」表 建档捷径：输入 新一个客户 苏州侦儿 → 自动识别 → 弹确认卡（客户名称 / 联系人 / 联系方式 / 客户地址 / 渠道）→ 确认写入「客户档案」表并记一条修改日志；重名会被拦截
标签：给随手记打标便于回看；客户下拉：把这条记录挂到某个客户名下
每日打卡 9 个时间节点打卡，点方框即写「每日打卡」表 顶部 已完成 X / 9 + 未完成 X 项（全打完变绿）；每行右侧有 已完成/未完成
点击即时反馈：toast「已打卡：xxx」+ 界面立刻变勾 + 顶部常驻结果行 ✓ 已保存：xxx → 已完成；写库失败红字 ✗ 没保存上：<真实错误> 并回滚
今日无记录时点方框会自动创建当天记录（不会重复建）
客户档案 按客户分组管理档案 + 订货明细，行内编辑 点客户块的「编辑」→ 主数据（联系人 / 联系方式 / 客户地址 / 渠道）+ 订货多行（产品 / 数量 / 金额 / 日期 / 渠道）
产品联想：产品名输入自动带出 规格 · 参考价（参考价取该 SKU 最近一次订货单价）；填数量后金额 = 数量 × 参考价自动预填，手动改过就不再覆盖
「+ 增加一行」录多产品；查重：同客户 + 同产品 + 同数量 + 同金额会被拦截，按钮变「仍要保存」才强制写入
修改历史：每个客户块内嵌该客户最近记录（默认 3 条，超出出「展开全部」）；底部全局日志随选中客户过滤

排障速查

按现象对症状，先看这里再问人
现象原因 / 处理
顶部有红色横幅「你打开的是本地文件」开的是 file:// 本地 HTML，没有云端能力 → 点横幅「打开在线版本」，或直接开 编辑版链接
诊断行 __SMART_PAGE__ 不存在平台 SDK 没注入（本地文件 / 外壳环境）→ 见上一条
诊断行 __SMART_PAGE__ 存在但无 databaseSDK 挂载不完整 → 点「立即重连」；仍失败刷新页面
打卡点了没反应看打卡区那行结果：✓ 已保存=成功；✗ 没保存上：<错误>=写库失败，把错误原文报出来
数据像没更新先看版本戳（打卡区日期旁 v25）确认是不是新版；再确认诊断行是 SDK 已连接
想确认是否真落库点「深度诊断」看容器形态/注入脚本/挂载状态；服务端可查「打卡」表今日记录
